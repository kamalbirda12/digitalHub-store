# DigitalHub Store v3

Backend-ready digital product store starter.

## Included
- Product catalog, search and categories
- Product detail modal
- Cart with quantity/remove
- Coupon support (demo coupon: SAVE10)
- Checkout form
- Order creation API
- Admin product creation API
- Secure-download endpoint structure
- Payment webhook placeholder
- Responsive frontend

## Run
1. Install Node.js 18+.
2. Open terminal in this folder.
3. `npm install`
4. `npm start`
5. Open http://localhost:3000

## Production
Connect a real database, authentication, cloud/private file storage, HTTPS and a payment gateway. Never put payment secrets in frontend code.
